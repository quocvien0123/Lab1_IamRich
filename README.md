## 1. Giới thiệu
Ứng dụng **I Am Rich** được xây dựng bằng React Native và Expo theo yêu cầu bài thực hành LAB 01. Giao diện đơn giản, sang trọng, hiển thị hình ảnh viên kim cương ở giữa màn hình kèm tiêu đề và thông tin sinh viên thực hiện.

## 2. Công nghệ sử dụng
- **React Native** (v0.86.3)
- **TypeScript**
- **Expo SDK** (~57.0.25)
- **Expo Status Bar**
- Các component cơ bản: `View`, `Text`, `Image`, `StyleSheet`

## 3. Cách chạy project

### Cài đặt dependencies:
```bash
npm install
```

### Khởi chạy ứng dụng:
```bash
npx expo start
```

- Nhấn phím `a` trên terminal để mở trên **Android Emulator / Thiết bị Android**.
- Quét mã QR bằng ứng dụng **Expo Go** trên điện thoại nếu dùng thiết bị thật.
"# Lab1_IamRich"
